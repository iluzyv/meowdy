# MEOWDY

Static one-page landing site for the $MEOWDY meme project.

## Vercel
Import this GitHub repository into Vercel. No framework preset or build command is required.
The output directory should remain blank/default because `index.html` is at the repository root.

## Update the contract
In `index.html`, replace `Contract address coming soon.` and the disabled `CA: COMING SOON` button when the contract address is ready.

## Local preview
Open `index.html` directly in a browser or run a simple local static server.
